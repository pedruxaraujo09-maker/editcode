# PROGRASO

Editor de código com foco inicial em Android e possibilidade de expansão futura
para desktop. O projeto está na etapa de organização e documentação da
arquitetura; nenhuma tecnologia de implementação foi definida.

## Documentação do projeto

A base técnica para o desenvolvimento está em [`agentes/`](agentes/). Comece
por [`agentes/INDICE.md`](agentes/INDICE.md), que apresenta o estado atual dos
documentos e indica quais consultar para cada tarefa.

Não há código do aplicativo implementado neste repositório neste momento.
